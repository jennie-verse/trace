# Trace 사용자 가이드

## 1. 처음 열기

1. iPhone 또는 iPad의 Safari에서 `https://jennie-verse.github.io/trace/`를 엽니다.
2. 처음 실행하면 이 저장 공간의 이름을 묻습니다. `iphone`, `ipad`, `iphone safari`처럼 알아보기 쉬운 이름을 입력합니다.
3. 이 이름은 화면에 표시하는 Context 이름입니다. 동기화 파일에 쓰는 고유 ID는 `sync.js`가 별도로 만들며, Context 이름을 나중에 바꿔도 고유 ID는 유지됩니다.

같은 기기에서도 Safari 탭과 홈 화면에 설치한 PWA의 저장 공간이 분리될 수 있습니다. 각각 처음 실행 안내가 나오면 서로 구분되는 이름을 사용하면 됩니다.

## 2. GitHub 토큰 연결

1. 오른쪽 위 **Settings**를 누릅니다.
2. **GitHub token** 입력란에 `webapp-data` 비공개 저장소를 읽고 쓸 수 있는 Personal Access Token을 붙여 넣습니다.
3. **Save**를 누릅니다.
4. 저장되면 **Saved · ending 1234**와 같이 마지막 네 자리만 표시됩니다.
5. **Refresh**를 눌러 데이터를 바로 읽을 수 있습니다.

토큰은 현재 브라우저 저장 공간의 `sync.token.v1`에 저장되며, 같은 오리진의 Atlas·Clip과 공유됩니다. 토큰 전체 값은 타임라인, 캐시, 메모 파일, outbox에 기록하지 않습니다.

토큰을 지우려면 **Settings → GitHub token → Clear**를 누르고 확인합니다. 지운 뒤 다시 연결하려면 새 토큰을 입력하고 **Save**를 누릅니다.

## 3. 하루 타임라인 보기

- 왼쪽 화살표를 누르면 이전 날짜로 이동합니다.
- 오른쪽 화살표를 누르면 다음 날짜로 이동합니다.
- 미래 날짜에는 이동할 수 없습니다.
- 다른 날짜를 보고 있을 때 **Today**를 누르면 오늘로 돌아옵니다.
- 각 행에는 시각, 앱 이름 `CLIP`, `Saved a clip`, 그리고 라벨 또는 내용 일부가 한 줄로 표시됩니다.
- 타임라인 아래에는 `3 clips saved`처럼 선택한 날짜의 중립적인 개수만 표시됩니다.
- 기록이 없는 날짜에는 `No entries this day` 한 줄만 표시됩니다.

시각과 날짜는 기기의 현재 지역 시간대를 기준으로 계산합니다. 한글 라벨과 클립 내용도 그대로 표시됩니다.

## 4. 하루 한 줄 메모

1. 화면 아래의 **One line (optional)** 입력란을 누릅니다.
2. 선택한 날짜의 메모를 한 줄로 입력합니다.
3. 입력 내용은 즉시 기기에 저장됩니다.
4. 입력이 멈춘 뒤 4초가 지나면 GitHub의 `trace/memo.<contextId>.json` 파일에 전송됩니다.

한글 입력기의 글자 조합 중에는 중간 상태를 따로 전송하지 않고, 조합이 끝난 값을 저장합니다. 날짜를 바꾸면 각 날짜의 메모가 해당 날짜에 다시 표시됩니다.

오프라인에서도 메모를 입력할 수 있습니다. 전송할 내용은 outbox에 보관되고 온라인으로 돌아오면 자동으로 다시 전송됩니다. **Settings → Sync**의 `N to send`에서 대기 중인 파일 수를 확인할 수 있습니다.

## 5. 새로고침과 상태 확인

**Settings → Sync**에서 다음 정보를 확인합니다.

- **Refresh**: GitHub의 Clip 데이터와 Trace 메모를 다시 읽습니다.
- **Updated ...**: 원격 데이터를 마지막으로 읽은 시각입니다.
- **No errors** 또는 오류 안내: 마지막 동기화 상태입니다.
- **N to send**: 온라인 복귀 시 보낼 outbox 파일 수입니다.

인증 오류가 표시되면 토큰이 저장되어 있는지, 토큰에 비공개 저장소 접근 권한이 있는지 확인한 뒤 **Refresh**를 다시 누릅니다. 오프라인이면 메인 화면에 `Offline · cached data is shown`이 한 줄로 표시됩니다.

## 6. Context 이름 바꾸기

1. **Settings → Context → Change**를 누릅니다.
2. 새 이름을 입력합니다.
3. 확인하면 Settings에 새 이름이 표시됩니다.

이 작업은 화면에 보이는 이름만 바꿉니다. 기존 `memo.<contextId>.json` 파일과의 연결은 그대로 유지됩니다.

## 7. 글자 크기

**Settings → Text size**에서 6, 8, 10, 12, 14, 17 중 하나를 선택합니다. 기본값은 12px입니다. **Reset**을 누르면 12px로 돌아갑니다.

글자를 작게 선택해도 버튼의 터치 영역은 44×44px 이상으로 유지되고, 메모와 토큰 입력란은 iPhone Safari의 자동 확대를 피하도록 16px를 유지합니다.

## 8. 홈 화면에 설치

1. Safari에서 Trace를 엽니다.
2. Safari의 **공유(Share)** 버튼을 누릅니다.
3. **홈 화면에 추가(Add to Home Screen)**를 선택합니다.
4. 이름이 `Trace`인지 확인하고 **추가(Add)**를 누릅니다.
5. 홈 화면의 Trace 아이콘을 눌러 standalone 화면으로 실행합니다.

## 9. 데이터 보관과 복구

타임라인의 원본 Clip 데이터와 Trace 메모는 GitHub 비공개 저장소 `webapp-data`에 JSON 파일로 남습니다. GitHub 저장소의 파일 기록에서 이전 커밋을 확인할 수 있습니다. 기기에는 다음 데이터가 별도로 저장됩니다.

```text
sync.token.v1      GitHub 토큰
trace.cache.v1     마지막으로 읽은 타임라인과 원격 메모 캐시
trace.local.v1     현재 Context의 즉시 저장 메모
trace.settings.v1  글자 크기
```

Safari의 웹사이트 데이터를 지우면 이 기기의 토큰, Context ID, 캐시, 로컬 메모가 함께 지워질 수 있습니다. GitHub에 전송된 JSON은 저장소에 남지만, 아직 outbox에 있던 데이터는 브라우저 저장 공간과 함께 지워질 수 있습니다. 웹사이트 데이터를 지우기 전에는 Settings의 `0 to send`를 확인하고 온라인 상태에서 **Refresh**를 한 번 실행하는 것이 좋습니다.

## 10. 업데이트 화면이 바뀌지 않을 때

1. 인터넷 연결을 확인합니다.
2. Safari 탭을 닫고 Trace를 다시 엽니다.
3. 홈 화면 앱이라면 앱 전환 화면에서 Trace를 완전히 종료한 뒤 다시 엽니다.
4. 그래도 이전 화면이 보이면 Safari에서 사이트를 한 번 연 뒤 새로고침하고, 홈 화면 앱을 다시 실행합니다.

앱 배포자가 `sw.js`를 수정할 때 `CACHE_NAME` 버전을 올리면 새 앱 셸이 활성화될 때 이전 버전 캐시가 정리됩니다.
